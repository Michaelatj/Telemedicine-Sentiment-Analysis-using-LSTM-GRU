# Start here

1. Extract the ZIP.
2. Open the `telemedicine-sentiment-analysis-lstm-gru` folder in VS Code.
3. Read `README.md` and `docs/TEAM_TASKS.md`.
4. Download the dataset and place the CSV in `data/raw/` as described in `data/README.md`.
5. Configure Git identity, then run `scripts/setup_branches.ps1` (Windows) or `scripts/setup_branches.sh` (macOS/Linux/Git Bash).
6. Create an empty GitHub repository and push `main` plus all feature branches. See README for commands.
7. Start with notebook `01_data_exploration.ipynb`.

**Branch reminder:** feature branches are not folders. After switching to a branch, you remain in the same project directory; Git updates the working files to that branch's version.
